## Overview

This website itself is a project—a professional portfolio built to showcase work, experience, and research. It features a dark-first design with a clean, accessible layout that presents writing samples, academic projects, professional artifacts, and a resume. The site prioritizes readability and professionalism while remaining easy to maintain and update as new work is completed.

The full source code, documentation, and local development setup are available [on GitHub](https://github.com/Garrett-Ferrara/garrett-ferrara.github.io).
